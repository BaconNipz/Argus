# Argus v0.12.0 — Quicker access to Command

This update adds two convenient ways to open the existing voice controls: a home-screen shortcut and a tile in Android's swipe-down panel. Open Command, tap **Start listening**, review the recognised words, then run the command when ready. All processing and permissions follow the existing on-device speech flow.

## Add the home-screen shortcut

1. Open the updated Argus app once, then go to **Command → Open Command faster**.
2. Tap **Pin home-screen shortcut** and confirm **Add** in the launcher prompt.
3. Find **Command** on your home screen. Tap it to open Argus directly at the voice controls.

You can also long-press the normal Argus app icon and choose **Command** in launchers that support app shortcuts. Some launchers let you drag that entry onto the home screen. If pinning is unavailable, Argus explains the alternatives. **Refresh access** checks launcher support and whether Android reports a pinned shortcut.

Requesting a pin does not prove that it was added: Android does not send a cancellation callback. Check the actual home screen after confirming. A pinned shortcut reported by Android may belong to another launcher. These distinctions follow Android's [shortcut creation APIs](https://developer.android.com/develop/ui/compose/system/shortcuts/creating-shortcuts).

## Add the Quick Settings tile

1. In **Command → Open Command faster**, tap **Add Quick Settings tile** and confirm Android's prompt.
2. Swipe down to find the **Argus** tile. You may need to swipe down twice or move to another tile page.
3. Tap **Argus** to open Command. If the phone is locked, unlock it first.

If the button is unavailable or Android declines the request, swipe down twice, open **Edit** and drag **Argus** into your active tiles. You can place it near the top for easier access. Button names and placement can differ between Android/Samsung versions. The in-app prompt requires Android 13 or later; the manual tile remains available on supported older Argus devices. See Android's [Quick Settings tile guide](https://developer.android.com/develop/ui/views/quicksettings-tiles).

The tile uses an inactive appearance because it opens a screen; it does not indicate that Argus is listening. Removing a tile or shortcut only removes that entry point. It does not delete your Argus data.

## What happens when you open Command

- A running Argus activity is reused, preserving the typed command draft in memory. A cold start loads local data before opening Command.
- Repeated or stale launch requests cannot execute twice. A newer share, reminder or normal app intent supersedes an older pending Command request.
- If a backup, restore, routine change or command is still finishing, navigation waits for it to finish. A system file picker may close when Android brings Argus forward; a cancelled export is not reported as a verified backup.
- Speech capture/output from an earlier session is stopped on resume/navigation. The shortcut does not start a new recording, run the text in the box or approve an action.
- Android activity recreation or process death can discard unsaved typed drafts, just as before. This update does not add draft persistence.

Dynamic shortcuts allow the activity reuse flags needed here. Android's default static shortcut flags can clear the existing task, so this implementation uses the [dynamic shortcut approach](https://developer.android.com/develop/ui/compose/system/shortcuts/managing-shortcuts). The tile follows the API 34+ [PendingIntent launch method](https://developer.android.com/reference/android/service/quicksettings/TileService#startActivityAndCollapse(android.app.PendingIntent)).

## Phone checks

1. Add both entry points and open each with Argus already running and after closing it from Recents. Each should reach Command without microphone activity.
2. Type an unfinished command, go home and reopen using the shortcut or tile. The words should remain when Android has kept the activity alive, and nothing should run automatically.
3. Tap the tile while locked. Cancel unlocking, then try again and unlock. Command should open only after successful unlocking.
4. Cancel a pin/tile setup request and check the status. Remove a tile, then add it again using Edit or the app prompt.
5. While saving a backup, open Command from the tile. If the picker is cancelled, repeat the save from Settings and wait for **Backup saved and checked** before relying on the file.
6. Use Start listening and try the broader command examples from the [v0.11 guide](v0.11.0.md).

## Voice activation and build limits

This is a shortcut update. “Hey Argus” remains an optional prefix **after** you tap Start listening; it does not wake the app in the background. The next voice development task is a separately opt-in wake-detector prototype, measured for accidental activations and battery use on the phone. It will not be simulated by continuously restarting the normal speech recognizer.

Version **0.12.0**, Android version code **13**, database schema **4**. Automated coverage checks launch readiness/busy/visibility gates, token consumption, superseded requests, recreation and bridge restrictions. CI runs the JavaScript/native tests and builds the APK. Launcher placement, lock-screen behavior, interrupted file pickers and microphone use still need physical-phone testing.

The development APK is debug-signed and may not install over a build signed with another debug key. This update does not resolve the release-signing setup. Keep the existing installation and data if Android rejects the update; use only a verified backup before any later reinstall decision.
