# Argus v0.8.0 — spoken commands

This build adds a microphone option to Command. Speak a short instruction, check what Argus heard, then use that text in the command box. You still decide when to run it.

## How to use it

1. Open **Command** in the v0.8 Android APK.
2. Check the speech status. If an on-device engine is available, choose your spoken language and tap **Allow microphone** if needed.
3. Tap **Start listening**, then speak a command such as “remember that I need to export a backup”.
4. Pause to let recognition finish, or tap **Finish speaking**. Use **Cancel recording** to discard that capture.
5. Read the recognised text and tap **Use text in command box**. Correct anything it misheard, then tap **Run Command**.

Recognition never runs a command on its own. Your existing typed command stays separate from the speech result until you tap Use text. External actions, including opening a URL, still require approval through the existing action queue.

## Offline support

This adapter requires Android 12 or later and an available on-device speech service. Argus checks availability and creates only the dedicated on-device recognizer. It does not fall back to Android's generic recognizer or a browser speech service. This is based on [Android's on-device recognition API](https://developer.android.com/reference/android/speech/SpeechRecognizer#createOnDeviceSpeechRecognizer(android.content.Context)).

A speech service being available does not mean every language pack is installed. Choose the phone's language, English (Australia), English (United States) or English (United Kingdom). On Android 13+, expand **Check or download an offline language** and tap **Check language**. If a pack is missing, **Request language download** asks Android to obtain it. The download needs internet access and may show a system confirmation. Check the language again afterwards; a download request does not guarantee installation. See [Android's language-download API](https://developer.android.com/reference/android/speech/SpeechRecognizer#triggerModelDownload(android.content.Intent)).

If your phone cannot provide this service or language, the screen says so and typing remains available. The app includes links to Android voice settings and Argus app permissions. A future update can add a bundled offline speech engine if device testing shows the system adapter is insufficient.

## Recording controls

Argus starts a command recording only after you tap Start listening. It ends a capture after at most 30 seconds and allows up to 10 seconds for the final result. Leaving the Command screen, putting Argus in the background or cancelling releases the speech recognizer. Results from old or cancelled sessions are ignored.

Argus does not save an audio file for command capture. Recognised text is held in the current app session until you choose to use it. A resulting memory or other command output is saved only when you run the command. The existing Voice section still records voice notes separately; this update does not transcribe saved recordings.

## What this version includes

- A phone-first spoken-command panel, status messages and partial speech feedback.
- Microphone permission handling, language selection and optional language-pack setup.
- Recognised-text review before command entry or execution.
- Existing v0.7 reminder and routine features.
- The same local database schema; no new memory or reminder migration.

This is input recognition through Android's system adapter, not a general conversational AI model. The rule-based command vocabulary is unchanged. The existing optional Speak Reply feature remains separate; native offline voice-output selection is a following task.

## Checks and remaining device validation

Automated tests cover transcript review states, cancellation and stale callbacks, duplicate results, permission/language errors and unsupported-device handling. CI also runs the existing reminder timing tests and compiles the APK. The APK's binary manifest and bundled web assets are checked before delivery.

Desktop checks cannot establish whether a particular S23 Ultra has a suitable speech service or language installed. Actual recognition quality, microphone behaviour, offline operation and Samsung lifecycle behaviour still need device testing. The local browser-preview connection was blocked in this workspace, so no visual-device pass is claimed.

Version: **0.8.0**, Android version code **9**. Development APKs are still debug-signed while permanent release signing awaits configuration. The v0.8 development branch is based on v0.7; its pull request targets the v0.7 branch so the two feature slices remain reviewable.
