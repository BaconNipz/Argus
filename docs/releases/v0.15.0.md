# Argus v0.15 — Reviewed Phone Actions

This development build lets Argus prepare three useful tasks for other Android apps. It includes the v0.14.1 wake feedback repair and keeps the same wake listener, model and sensitivity settings while that version is being tested.

## Commands you can use

| Task | Example | What happens after review and approval |
| --- | --- | --- |
| Find a place | “Show Adelaide Oval on maps” or “Could you open maps for Adelaide Oval?” | Opens the place search in a compatible map app. Choose the result and any directions there. |
| Prepare a call | “Open the dialer for 12345” or “Dial 12345” | Opens those digits in the dialer. You still press Call yourself. The example uses dummy digits; replace them with the number you intend to use. |
| Share chosen text | “Share this text: I'm on my way.” | Opens Android’s share chooser with that text. You choose the app and recipient and finish there. |

You can add “Hey Argus”, “please” or “could you” to supported requests. The command rules run locally. Wake-triggered commands also produce drafts; voice does not approve or open these phone actions automatically.

For dialer requests, use explicit digits with an optional + country code. Spaces, parentheses and hyphens are accepted and removed in the reviewed number. Contact names, spoken number words, extensions and service codes are unsupported. If speech recognition returns words instead of digits, correct the number in the editor. Argus does not guess a contact.

## Review and edit

1. Run a typed or recognised command, or open **Bridge → Prepare a phone action**.
2. Enter the place, number or chosen text and select **Save for review**.
3. Check the full value on the saved card. **Edit draft** lets you correct it. Saving changes returns the action to draft and clears approval.
4. Select **Approve**, then **Open Maps**, **Open dialer** or **Choose app to share**.
5. Finish the task in the other app. A successful launch is recorded as **handed off**; it does not mean a call was placed, directions started or a message sent. Cancelling the chooser still leaves a truthful handoff record.

**Dismiss draft** cancels a saved draft. **Create another draft** lets you repeat a previous handoff with a fresh review. Repeated taps on an active handoff are suppressed. If no compatible app is available, Argus explains the problem and requires another review and approval before retrying.

The editor preserves line breaks and punctuation in shared text. It also accepts complex literal text that the one-command parser may decline. Nothing is pulled automatically from contacts, the clipboard, saved notes or a current investigation.

## Data and Android behavior

Drafts and handoff history stay in the existing local action store and travel with Argus backups. Restored pending actions return to draft; previous handoff records retain their status. Backup format remains schema 4.

Native launch requires the phone to be unlocked and Argus to have foreground focus. The three actions add package-visibility queries for compatible apps, with no new Android permissions. Maps and receiving apps may use their own network access and settings. The Android implementation follows [common intents](https://developer.android.com/guide/components/intents-common) and [text sharing through the chooser](https://developer.android.com/develop/ui/compose/sharing/send).

Finish the current v0.14.1 wake test first. In this build, try one map search, open your chosen number without pressing Call, and open then cancel the share chooser. Check that editing an approved draft asks for approval again. Recognition accuracy and the behavior of the installed Maps, dialer and sharing apps still need device testing.

This is v0.15.0 / Android versionCode 17, an ARM64 development APK. It is not a signed production release. Keep a backup before changing installations; development signing can prevent installing over a previous debug build.
